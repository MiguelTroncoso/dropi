# playbook

Guías paso a paso para lanzar y correr la campaña de Facebook Ads del
Producto #1, pensadas para alguien sin experiencia previa en ads. Léelas
en orden — cada una asume que ya hiciste la anterior:

1. [`01-setup-inicial.md`](./01-setup-inicial.md) — Business Manager,
   cuenta publicitaria, página, verificación de dominio, Pixel + CAPI.
2. [`02-campana-facebook-paso-a-paso.md`](./02-campana-facebook-paso-a-paso.md) —
   estructura de campaña simple para COD, presupuesto, público, qué no
   tocar los primeros días.
3. [`03-lectura-de-metricas.md`](./03-lectura-de-metricas.md) — qué
   significa cada métrica y por qué el ROAS que muestra Meta no es el
   ROAS real en COD.
4. [`04-reglas-matar-escalar.md`](./04-reglas-matar-escalar.md) — cuándo
   pausar y cuándo subir presupuesto, con reglas concretas.
5. [`05-creativos.md`](./05-creativos.md) — grabar con celular, editar en
   CapCut, armar imágenes en Canva con el output del creative-kit.
6. [`06-checklist-lanzamiento.md`](./06-checklist-lanzamiento.md) —
   checklist final (legal + técnico + ads) antes de gastar el primer peso.
